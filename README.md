Этот проект состоит из нескольких частей. Сначала поработаем с данными сервиса Яндекс Книги, рассчитаем несколько метрик и проверим гипотезу. Затем, уже на других данных, проанализируем результаты A/B-тестирования для интернет-магазина BitMotion Kit.

Таблицы основной части проекта содержат данные о чтении и прослушивании контента в сервисе Яндекс Книги, которые включают следующую информацию:
- Таблица `bookmate.audition` содержит данные об активности пользователей.
- Таблица `bookmate.content` содержит данные о контенте.
- Таблица `bookmate.author` содержит данные об авторах контента.
- Таблица `bookmate.geo` содержит данные о местоположении.
